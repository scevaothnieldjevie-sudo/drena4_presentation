# Extraits de code – Application DRENA4

Ce dossier présente une sélection d'extraits illustrant certaines fonctionnalités développées dans le cadre du projet de gestion de la distribution des cartes d'identité scolaires à la DRENA4.

## Extraits disponibles

### 1. connexion.php
Exemple de connexion à une base de données MySQL avec PDO.

### 2. gestion-paquets.php
Exemple simplifié du traitement d'enregistrement des paquets de cartes.

### 3. synchronisation-statuts.php
Illustration de la logique de mise à jour des statuts des élèves en fonction des quantités de cartes distribuées.

## Technologies utilisées
- PHP
- PDO
- MySQL
- SQL

**Important :** Ces fichiers sont des extraits de démonstration. Ils ne constituent pas l'application complète et ne sont pas destinés à être exécutés indépendamment.
